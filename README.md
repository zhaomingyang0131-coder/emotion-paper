# 情绪小纸条

一个给情绪留出空间的简单网页。你可以在纸上写下或录下不开心的事，然后选择从中撕开、粉碎，或揉成纸团扔进垃圾桶，再收到一句随机的安慰。

## 如何使用

1. 下载项目，双击打开 `index.html`，或将文件拖进浏览器。
2. 在纸上写字，或点击“开始录音”，允许麦克风权限后说出心事。结束录音后可以回听或单独删除。
3. 点击“放大到全屏”，可以用更大的纸书写；按 Esc 或点击“退出全屏”恢复。
4. 点击下方的一种方式，纸张会消失，文字和录音也会一起清除。
5. 页面会随机显示一句安慰语，并尝试使用本机中文声音朗读。可以点击“听一听”重播、“换一句”或“再写一张”。

使用网页不需要注册账号、连接服务器或配置 API。录音需要浏览器支持并授权麦克风；如直接打开本地文件时浏览器不允许录音，可用支持本地文件录音的新版 Chrome 或 Edge。

朗读只选择浏览器报告为**本地**的中文语音，不使用在线语音。不同设备的声音可用情况不同；如果设备没有本地中文语音，请在操作系统中安装，或者只看文字。如果浏览器阻止自动播放，可点击“听一听”。

## 设计思路

有时人需要的不是立刻解决问题，而是一个可以表达情绪的小空间。项目用一张纸承载文字，用三种不同的动作提供象征性的释放方式。界面采用温暖、安静的颜色，希望给使用者一点喘息的空间。

项目使用 HTML、CSS 和原生 JavaScript 实现。纸张动画通过 CSS 动画和 JavaScript 创建的纸张碎片实现；通过浏览器的 MediaRecorder 本地录音、音频播放器回放和本地语音合成朗读安慰语。支持电脑和手机浏览器，并尊重系统的减少动态效果设置。

## 隐私说明

文字和录音只存在当前浏览器页面中，不会上传到服务器，也不会由网页存入本地存储。刷新或关闭页面后，未释放的内容也会消失。点击释放后，页面会清除录音、文字和动画中的文字副本，并关闭麦克风。

为了避免将声音交给可能联网的识别服务，本项目**不提供语音转文字**。录音可以回放，文字需要自行输入。请在安静、私密的环境中使用；浏览器扩展和设备自身的软件不受本网页控制。

这个网页是情绪表达工具，不提供心理诊断或治疗，也不能替代专业帮助。

## 开发方式

项目通过 vibe coding 开发：先用自然语言描述想法和交互效果，再与 AI 协作编写、调整和测试代码。
