# 情绪小纸条 · 慢慢发现自己

一个给自己留一点空间的网页。它从学业压力、就业困惑和面对任务时的犹豫出发，提供私密表达、真实资料、整理想法和自选行动的入口。可以按自己的需要使用，也可以随时停下。

项目的第一位使用者是开发者自己。它是一个持续探索中的课程原型，不提供心理诊断或治疗，也不能代替专业帮助。

## 现在可以做什么

- **写下心事**：在纸上打字或录音，回听录音；选择撕开、粉碎或揉团丢掉。放下前需要确认，之后文字和录音会清除。
- **随机遇见**：每次主动点击，随机看到一条有来源的自然或天文资料，或一段公有领域古诗，也可以再换一条。事实内容基于公开资料整理，古诗原文会明确标识作者和来源；不冒充他人写作。将来如收录其他人写的文字或图片，会先确认授权和署名方式。
- **慢慢认识自己**：把兴趣、已有能力以及现实限制分开写下来。每项都可跳过，网页不会分析或评价回答。
- **面对一点点**：自主选择学业、就业或不确定，看看一些可选的小步骤，也可以写下自己的想法。不计时、不打卡，不强迫完成。
- **寻找现实支持**：可以了解信任的人、学校心理咨询或就业指导等支持。网页不会自动联系或发送消息。

## 如何使用

下载仓库后，双击 `index.html` 或将它拖进浏览器。不需要注册账号、安装依赖、配置 API 或启动服务器。

纸张可以放大到全屏，使用浏览器支持的麦克风录音（最长 2 分钟）；录音可以回放或单独删除，不会转成文字。直接打开本地文件时，麦克风是否可用取决于浏览器和权限；建议使用新版 Chrome 或 Edge。

纸张放下后会出现原有的随机安慰语。朗读默认不自动播放；点击“听一听”时，只选择浏览器报告为本地的中文声音。如果设备没有本地中文声音，可以只看文字。

## 隐私

- 网页没有后台提交功能，也不使用统计脚本。心事、录音、整理自己的输入和下一步想法只存在当前页面，不会被网页上传或保存到本地存储。通过在线托管访问时，页面文件会从托管服务器加载。
- 刷新或关闭页面后，未放下的内容也会消失。放下纸张前会提示，确认后文字和录音无法找回；录音会停止，浏览器音频地址也会清除。
- 切换到其他入口时，正在进行的录音会停止。打开“随机遇见”的外部来源链接时，才会访问对应的外部网站；外部网站可能有自己的隐私政策。
- 为了避免将声音交给可能联网的识别服务，不提供语音转文字。浏览器扩展、操作系统及设备自身软件不受本网页控制。

## 设计与课程方向

网页不是要替使用者决定什么才是正确选择。表达情绪、阅读资料、整理想法和尝试行动是并列入口，休息或离开也是选择。内容不会根据用户的输入推断心理状况。

本原型体现的是围绕个人处境的选择与决策，**目前不属于大数据分析项目**。后续可以研究能否引用可靠、标注来源的公开汇总资料，帮助使用者了解学业与就业环境；公开数据与个人私密内容应分开处理。

项目使用 HTML、CSS 和原生 JavaScript 实现。没有后端和数据库。通过 vibe coding 开发：由使用者提出需求和体验方向，与 AI 协作实现与测试。现有随机安慰语是原型文案，并非真实用户投稿或来自外部作品的引文。
